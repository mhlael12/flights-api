# ✈️ Fly Genie API

A professional RESTful API built with **Node.js**, **Express**, and **MongoDB** to manage flight schedules and travel data.

## 🚀 Features
- **Create Flights**: Add new flight details to the database.
- **View All Flights**: Fetch a complete list of available flights.
- **Cloud Integration**: Fully connected with **MongoDB Atlas**.
- **Environment Safety**: Uses `dotenv` to protect sensitive credentials.

## 🛠️ Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose ODM)
- **Tools:** Git, Postman, dotenv
